# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in a public issue or discussion.

Use GitHub's private vulnerability reporting from the repository **Security**
tab. Include the affected endpoint or component, reproduction steps, expected
impact, and any suggested mitigation. If private reporting is unavailable,
contact a repository owner privately through GitHub before sharing details.

Please do not access, modify, or retain other users' data while investigating a
potential issue. Maintainers will acknowledge a report, assess its severity,
and coordinate disclosure after a fix is available.

## Supported version

Security fixes target the revision currently deployed from `develop` and are
then promoted to the stable `main` branch after verification.
