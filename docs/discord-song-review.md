# Discord 미등록 곡 수동 등록

`/미등록목록`에서 곡을 선택하면 외부 공식 사이트 조회 없이 즉시 수동 입력 모달이 열립니다.
곡명·장르·아티스트는 미등록 보고서의 값을 사용합니다.

1. 존재하는 채보만 `N:25,H:38,EX:45` 형식으로 레벨을 입력합니다. 레벨은 1~50이며 중복 난이도는 거부합니다.
2. 곡·채보 버전, 일반/UPPER, 특수 게이지·판정을 확인합니다. 레벨과 버전은 자동 입력하지 않습니다.
3. 제출하면 입력한 정보의 미리보기가 표시됩니다. 아직 DB에 등록하지 않습니다.
4. 정보를 검토하고 **확인·등록**을 누르면 자켓 없이 등록합니다. 수정 또는 취소도 가능합니다.

추가일은 등록 시각, 채보 추가 버전은 입력한 버전을 사용하며 미리보기에 안내합니다.
입력 오류 시 **다시 입력** 버튼으로 돌아갈 수 있습니다. 요청 소유 관리자만 처리할 수 있으며
등록안은 15분 뒤 또는 서버 재시작 시 만료됩니다. 기존 곡 중복은 등록 트랜잭션에서 검사합니다.

등록은 비동기로 처리하며 **처리 상태 확인** 버튼으로 성공/실패 결과를 다시 읽을 수 있습니다.
결과 웹훅 전송이 실패해도 상태 확인은 등록을 반복하지 않습니다.
