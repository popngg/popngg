# Discord 미등록 곡 확인

`/미등록목록`에서 곡을 선택하면 서버가 공식 곡 목록을 조회합니다. 첫 조회는 전체 목록을
읽으므로 시간이 걸릴 수 있습니다. 곡 선택은 DB 등록을 실행하지 않습니다.

조회 시작 시 비공개 안내와 **처리 상태 확인** 버튼을 즉시 반환합니다. 조회 결과는 자동으로
같은 메시지에 표시됩니다. 자동 결과 전달이 실패한 경우 버튼으로 저장된 결과를 다시 읽을 수
있습니다. 버튼은 해당 요청을 시작한 관리자만 사용할 수 있으며 15분 동안 유효합니다.

조회가 성공하면 공식 정보 확인 화면에 채보별 레벨이 표시됩니다. **확인·등록**은 표시된 공식
레벨과 안내된 기본값으로 등록합니다. 등록 성공 후 결과 전달이 실패해도 상태 버튼으로 결과를
확인할 수 있으며, 같은 등록 버튼을 다시 누르는 것으로 중복 등록하지 않습니다.

공식 조회가 실패하거나 후보가 없으면 오류 또는 수동 등록 안내를 표시합니다. 이 기능은
서버의 비로그인 조회를 사용하므로 사용자별 해금곡을 모두 조회할 수 있다는 보장은 없습니다.
레벨을 직접 입력해야 하는 곡은 기존 `/곡추가`를 이용합니다.

운영 진단 시 `OfficialSongListClient`의 실패 버전·페이지·요청 수·예외 종류와
`OfficialSongReview`의 결과 전달 실패 로그를 확인합니다. Discord 토큰과 웹훅 URL은 기록하지
않습니다. 결과·등록안은 메모리에 보관되므로 서버 재시작 시에는 미등록 목록에서 다시 확인합니다.
