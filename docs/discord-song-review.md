# Discord 미등록 곡 수동 등록

`/미등록목록`에서 곡을 선택하면 기존 곡 추가 모달이 열립니다. 공식 사이트 조회는 하지 않습니다.
곡명·장르·아티스트·일반/UPPER 여부는 미등록 보고서의 값을 기본값으로 채웁니다.

1. 추가일, 곡·채보 버전과 존재하는 채보 레벨을 관리자가 직접 입력합니다.
2. 자켓은 선택 사항입니다. 첨부하면 자켓과 함께 등록하고, 비워 두면 `jacketUrl` 없이 등록합니다.
3. 제출하면 입력 정보와 자켓 첨부 여부를 JSON 미리보기로 표시합니다. 이 단계에서는 DB에 등록하지 않습니다.
4. **등록**을 누르면 곡과 채보를 등록하고 해당 미등록 보고서를 해결 처리합니다.

레벨 입력란에는 `L:[], N:[], H:[], EX:[]` 틀이 미리 표시됩니다. 존재하는 채보의 대괄호 안에만 숫자를 입력합니다.
자켓은 5MB 이하 이미지 파일만 허용합니다. 등록 요청은 15분 뒤 또는 서버 재시작 시 만료됩니다.
기존 곡 중복은 등록 트랜잭션에서 검사합니다.
