# Medal image source

These PNG files are transparent 64×64 raster copies of the medal SVGs served by the popn.gg frontend at
`https://popn.gg/icons/medal/{name}.svg`, captured on 2026-09-25.

The filenames follow `docs/medal-codes.md`: gold star; silver star, diamond, circle; bronze star,
diamond, circle; black star, diamond, circle; easy; long-off; none.
