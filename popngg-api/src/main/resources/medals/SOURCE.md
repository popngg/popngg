# Medal image source

These PNG files are transparent 128×128 raster copies of the official medal SVGs in the popn.gg frontend
`public/icons/medal` directory, rendered on 2026-09-25.

The filenames follow `docs/medal-codes.md`: gold star; silver star, diamond, circle; bronze star,
diamond, circle; black star, diamond, circle; easy; long-off; none.
